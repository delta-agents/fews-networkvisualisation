# FEWSVisualiser + Talk with Delft-FEWS

Voor Talk with FEWS moeten de configuraties van verschillende waterschappen worden geanalyseerd en gevisualiseerd. Dit project biedt een framework voor het analyseren en visualiseren van Delft-FEWS configuraties, met de mogelijkheid om verschillende analyses uit te voeren.

Maakt gebruik van de pixi omgeving om de analyses uit te voeren.
Paden gebruiken de P-schijf waar de FEWS configuraties staan.
